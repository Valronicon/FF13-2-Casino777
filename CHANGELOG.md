# Changelog

## 1.0.0

First release.

- Every slot machine spin in FINAL FANTASY XIII-2 (Steam) lands on 777.
- Installed as `dinput8.dll` next to `ffxiii2img.exe`; all DirectInput calls are forwarded to the system DLL.
- In-memory patch only, applied after verifying the original game code; inactive on unknown game versions.
- Writes `FF13Casino777.log` next to the game executable.
